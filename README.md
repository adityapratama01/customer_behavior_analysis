# customer_behavior_analysis
Data analytics project showcasing customer behavior analysis using Python, SQL, and Power BI.

# 📊 End-to-End Data Analytics Project

## 1. Overview

This project demonstrates an end-to-end data analytics workflow, starting from raw data collection and preparation to data visualization and reporting.

The objective is to transform raw data into meaningful insights using Python, PostgreSQL, and Power BI. The project includes Exploratory Data Analysis (EDA), data cleaning, SQL analysis, dashboard development, and business reporting.

This project showcases practical data analytics skills and the ability to turn data into actionable insights that support data-driven decision-making.

## 2. Dataset

The dataset used in this project is available directly in the root directory of this repository:
- customer_shopping_behavior.csv

The dataset was used to:
- Explore patterns and trends.
- Identify missing values and inconsistencies.
- Analyze key metrics and performance indicators.
- Generate insights through statistical and SQL analysis.

## 4. Project Steps

# Step 1: Data Loading
- Imported the dataset into Python.
- Inspected the dataset structure, columns, and data types.
- Reviewed the initial records to understand the data.

# Step 2: Exploratory Data Analysis (EDA)
- Analyzed data distributions and summary statistics.
- Identified trends, patterns, and relationships.
- Used visualizations to explore important variables.
- Investigated potential outliers and anomalies.

# Step 3: Data Cleaning & Preparation
- Handled missing and duplicate values.
- Corrected inconsistent data formats.
- Renamed columns where necessary.
- Standardized data types and values.
- Prepared the dataset for further analysis.

# Step 4: SQL Analysis with PostgreSQL
- Imported the cleaned dataset into PostgreSQL.
- Executed SQL queries to analyze the data.
- Used filtering, grouping, aggregation, and joins where applicable.
- Extracted key metrics and business insights.

# Step 5: Power BI Dashboard Development
- Connected Power BI to the prepared dataset.
- Created relevant KPIs and visualizations.
- Designed an interactive dashboard.
- Added filters and slicers for better data exploration.
- Highlighted key trends and performance indicators.

# Step 6: Reporting & Presentation
- Created a PDF report summarizing the analysis, findings, and insights.
- Developed a PowerPoint presentation to communicate the project's objectives, methodology, and key results.
- Presented findings in a clear and structured format.

## 8. How to Run

Follow these steps to reproduce the analysis:

# Prerequisites
- Python 3.x
- PostgreSQL
- Power BI Desktop
- Jupyter Notebook

# Installation

**1. Clone the repository**

`git clone https://github.com/adityapratama01/customer_behavior_analysis.git`

**2. Navigate to the project directory**

`cd customer_behavior_analysis`

**3. Install the required Python libraries**

`pip install pandas psycopg2-binary sqlalchemy notebook`

**4. Run the Python notebooks**

Open the notebooks in Jupyter Notebook and execute them in the following order:
1. Data Loading
2. Exploratory Data Analysis
3. Data Cleaning

**5. Run SQL queries**

- Create a PostgreSQL database.
- Import the cleaned dataset.
- Execute the SQL scripts located in the `sql/` folder.

**6. Open the Power BI dashboard**

Open `customer_behavior_dashboard.pbix` using Power BI Desktop to explore the interactive visualizations.

**7. Review the final deliverables**

Open the PDF report and PowerPoint presentation in their respective applications.
